📊 Project Overview
 Analyzed retail sales data to understand trends, clean data, build forecasts, and generate business insights.

🧹 1. Data Loading & Cleaning
- Imported libraries like Pandas, NumPy, Matplotlib, Seaborn
- Loaded a Retail Sales dataset
- Converted date columns to datetime
- Sorted records by date
- Removed duplicate rows
- Verified data types and checked missing values

📈 2. Exploratory Data Analysis (EDA)
- Total rows, categories, stores
- Revenue trends over time
- Daily, weekly, monthly patterns
- Store-wise & product-category-wise sales
- Revenue trends using visual charts (Plotly, Matplotlib)

📅 3. Time-Based Feature Engineering
Engineered features such as:
- Seasonal trends
- Weekly & quarterly indicators
- Store-level and category-level performance tracking

🤖 4. Forecasting Models Built
Implemented multiple forecasting approaches:
✅ Baseline Model
Last-value naive forecasting
✅ Prophet Model
Used Facebook Prophet for time-series forecasting
Captured yearly seasonality
✅ SARIMAX Model
Statistical time-series forecasting
✅ LightGBM Model
Machine learning forecasting
Used revenue, store, category & time features

📏 5. Model Evaluation
Evaluated models using:
- MAE (Mean Absolute Error)
- RMSE (Root Mean Squared Error)
Compared models:
-  Selected the best-performing model per store & category

🔮 6. 30-Day Sales Forecast
- Forecasted next 30 days revenue
- Generated forecasts per:
  Store
  Product category
  Total business

🏪 7. Store & Business Insights
Calculated business KPIs such as:
- Total revenue
- Units sold
- Average ticket size
- Store performance ranking
- Category revenue contribution

📊 8. Dashboard & Visualization Outputs
Produced:
- Store-wise revenue summaries
- Forecast charts
- Trend analysis plots
- Aggregated performance tables
